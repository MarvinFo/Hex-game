# Some game similar to The Settlers of Catan

It's an unfinished Unity project.

Implemented features:
* Play field generation, terrain hexes and numbering. 
* Calculating a spiral pattern to the center of the field depending on the start point. 
* Dice rolling and terrain hex indication of the rolled number.

Missing features are: 
* Game logic
* Resource manager implementation 
* Placement functionality of settlements and roads
* Assets and models for game objects

Tech Stack:
* Unity
* C#
